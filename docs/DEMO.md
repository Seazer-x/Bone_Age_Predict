# Demo

## Local demo

Run:

```bash
pip install -r requirements.txt
streamlit run Bone-pre.py
```

## Input

Recommended input:

- single hand X-ray image
- PNG/JPG/JPEG format
- clear hand positioning

## Output

The demo displays:

- detection status
- RUS-CHN scoring details
- estimated bone age

## Limitations

The demo is intended for research and education. It is not validated for clinical diagnosis or automated medical decision making.
