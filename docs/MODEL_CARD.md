# Model Card

## Summary

Bone_Age_Predict is a research/demo pipeline for hand X-ray bone age estimation using YOLOv5-based detection/classification and RUS-CHN scoring.

## Intended use

- Research prototypes
- Teaching
- Software engineering demonstrations

## Not intended for

- Clinical diagnosis
- Medical decision automation
- Replacement of qualified professionals

## Limitations

The repository does not currently publish clinical validation, external validation, demographic analysis, or uncertainty estimates.

Performance may vary across institutions, devices, image quality, and populations.

## Privacy

Do not upload identifiable patient images or protected health information to GitHub issues or pull requests.
